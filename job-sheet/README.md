# Job Sheets

This directory contains the job sheets and supporting documentation used during the implementation of the Ansible deployment project.

## Contents

### 1. WordPress Automation

Documentation for the automated deployment and configuration of WordPress using the `wordpress.yml` playbook.

The job sheet covers the steps required to prepare the target server and deploy the WordPress application using Ansible.

### 2. Blog Deployment

Documentation for the automated deployment and configuration of the blog application using the `blog.yml` playbook.

The job sheet covers the steps required to prepare the target server and deploy the blog application using Ansible.

## How to Use

Each job sheet provides step-by-step instructions and supporting information for the corresponding Ansible playbook.

Before following the job sheets, make sure the required AWS infrastructure, target servers, Ansible environment, and SSH access have been prepared.

Refer to the main [README](../README.md) for an overview of the complete project and deployment workflow.
